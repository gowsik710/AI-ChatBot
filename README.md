# 💬 AI Chatbot – Streamlit & OpenAI

## 📌 Project Overview

This project is an interactive AI-powered chatbot built using **Python, Streamlit, and the OpenAI API**. It allows users to communicate with an AI assistant through a simple and user-friendly chat interface.

The chatbot processes user messages using an OpenAI language model and generates relevant responses in real time.

## ✨ Features

- Interactive chat interface built with Streamlit.
- AI-generated responses using the OpenAI API.
- Maintains conversation history using Streamlit session state.
- Real-time question-and-answer interaction.
- Simple and user-friendly interface.
- Personalised chatbot interface with an image.

## 🛠️ Technologies Used

- **Python** – Core programming language.
- **Streamlit** – Web application interface.
- **OpenAI API** – AI-powered conversational responses.
- **Jupyter Notebook** – Development environment.

## ⚙️ Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/gowsik710/AI-ChatBot.git
   ```

2. Navigate to the project directory:

   ```bash
   cd AI-ChatBot
   ```

3. Install the required libraries:

   ```bash
   pip install streamlit openai
   ```

4. Configure your OpenAI API key securely using an environment variable. Never expose your API key in publicly shared code.

5. Open `AI-ChatBot.ipynb` using Jupyter Notebook or Google Colab.

## 🚀 How It Works

1. The user enters a message through the Streamlit chat interface.
2. The message is added to the conversation history.
3. The conversation history is sent to the OpenAI API.
4. The AI model processes the conversation and generates a response.
5. The chatbot displays the response to the user.
6. Conversation history is maintained throughout the session.

## 🎯 Project Objective

The objective of this project is to develop an AI-powered conversational application that demonstrates the integration of Python, Streamlit, and OpenAI's language models to create an interactive chatbot.
